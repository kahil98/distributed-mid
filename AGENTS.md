# Exam project workflow

- For each task, implement the requested module and test that it works before
  reporting completion.
- Include automated checks and verify the actual running services when relevant.
- Add or update `docs/<task-name>/README.md` with requirements, files changed,
  setup steps, commands, API behavior, test results, and remaining limitations.
- Link each task README from the root README.
- Distinguish implemented modules from later framework requirements. The overall
  target includes content-addressed chunks, multiple storage nodes, replication,
  erasure coding, and an S3-like API, evaluated on many-small and few-large files.
- Preserve raw verification/benchmark reports where useful for exam evidence.
