# Distributed Storage Project Submission

This package includes the source, runtime configuration, exam task documentation, automated checks, benchmark scripts, and recorded results.

## Included

- Python services: storage node, metadata/placement API, gateway, and repair worker.
- React/Vite frontend source and package lockfile.
- Dockerfiles for the combined local image and per-service images; Compose files for local dependencies and storage stack.
- Kubernetes manifests for storage StatefulSet and cloud gateway autoscaling template.
- Prometheus/Grafana, Nginx, Postman collection, environment example, and Python requirements/locks.
- `tests/` automated checks and `scripts/` verification/benchmark tools.
- `reports/` recorded XML/JSON verification and workload results.
- `docs/` task instructions and run/test commands.

Synthetic workload inputs are generated by `scripts/benchmark_storage.py`; they are not checked in as large binary fixtures. Recorded workload output is in `reports/workloads.json`.

## Quick verification

Run from this directory in PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
docker compose config --quiet
docker compose -f compose.storage.yaml config --quiet
```

The local `.env`, virtual environments, package caches, and generated build output are intentionally omitted. Copy `.env.example` to `.env` and set local secrets before starting Compose. See `README.md` and `docs/` for service-specific instructions and known limitations.
